# Draft A Lore

Draft A Lore is a free, offline-first creative studio for writers, students, worldbuilders, tabletop groups, and RPG creators. It brings manuscripts, notes, research, planning, art, audio, and playable branching adventures into one workspace.

There is no account, advertising, analytics, or telemetry. Your projects stay on your device unless you choose to export or copy them.

## Download

Get the newest files from the [latest GitHub release](https://github.com/Hexxis-cmd/Draft-A-Lore/releases/latest).

| Platform | File | How to use it |
| --- | --- | --- |
| Windows | `DraftALore-Windows.zip` | Extract the ZIP and open `DraftALore.exe`. Windows may show an **Unknown publisher** warning because the independent app is not code-signed. |
| Android | `DraftALore.apk` | Open the APK on your phone or tablet. Android may ask you to allow installations from your browser or file manager. |
| Web browser | `DraftALore.html` | Open the single HTML file in a modern browser. Nothing else needs to be installed. |

## Start a project

1. Open Draft A Lore and choose **New Project**.
2. Pick **Novel**, **RPG Adventure**, or **Novel + RPG**. Every project can still use the complete tool set.
3. Name the project, then begin in **Manuscript**, **Mind Map**, or **Story Graph**.
4. Use **File → Portable project bundle (.dalz)** to make a complete backup.

On a phone, use the top-left menu button to open the main navigation or project sections. Chapters also open in their own side drawer, leaving the manuscript room for writing.

## What you can do

### Write, study, and take notes

- Format chapters with headings, lists, quotes, links, colors, highlighting, callouts, verse blocks, checklists, tables, footnotes, and bookmarks.
- Add passage comments, revision labels, sources, and annotations.
- Find and replace text, follow the document outline, compare snapshots, and use focus or typewriter mode.
- Track goals, deadlines, streaks, word counts, and timed writing sprints.
- Read work aloud and adjust typeface, size, spacing, page tint, and drop capitals.
- Export manuscripts as plain text, Markdown, HTML, or Word `.docx`.

### Plan stories and worlds

- Build character profiles and relationship maps.
- Track plot threads, timelines, lore, locations, factions, and research.
- Create editable mind maps with connected ideas.
- Link several books or campaigns to one local **World Bible** of shared characters, lore, timeline events, and glossary terms.
- Run the offline **Continuity Checker** across prose, project records, RPG tables, and a linked World Bible; review, dismiss, or mark intentional findings.
- Use the **Living Encyclopedia** to review recurring people, places, objects, events, and facts found while you write.
- Compare chapter POV and pacing signals with transparent targets blended from up to five project genres.
- Upload cover art and assign illustrations to specific book pages.
- Search the whole project and restore earlier snapshots.

### Design and publish books

- Set trim size, margins, gutter, typography, indentation, drop capitals, page numbering, and chapter behavior.
- Preview the cover and pages in responsive, Android phone, Android tablet, Kindle, iPad, paperback, and hardcover frames.
- Run a publication check before exporting.
- Export a structured EPUB 3 book or use the print-formatted PDF workflow.

### Build and test RPG adventures

- Create branching scenes and endings in the visual Story Graph.
- Define stats, traits, items, equipment slots, inventory limits, conditions, effects, and failure rules.
- Attach artwork, music, ambience, sound effects, and narration to scenes.
- Play through an adventure at any time, step backward, and inspect state changes.
- Run **Story Checkup** to find unreachable scenes, broken links, impossible requirements, and stale references.
- Export a standalone playable adventure or Twine source.

## Back up or move a project

Draft A Lore stores work locally. It does not use an account or automatic cloud backup.

- Export a `.dalz` bundle to move a complete project between phone, tablet, browser, and PC. Chapter order, IDs, links, RPG data, annotations, art, and audio stay with the project.
- Import that bundle on the other device through **File → Import Project**.
- On supported browsers and Android, **Device Sync** can maintain either a one-device backup or a conflict-checked shared copy in a folder you choose. It keeps a readable `project.json`, chapter text files, and project assets together.
- Keep at least one backup somewhere other than the device you write on.

Clearing browser data, clearing Android app storage, uninstalling the app, or losing the device can remove projects that were not exported.

## Privacy and permissions

Draft A Lore has no advertising, analytics, telemetry, or user accounts. The Android app uses the system file and folder picker only after you choose an import, export, media, backup, or folder action. Optional Google Fonts are off by default.

Read the full [Privacy Policy](privacy-policy.html).

## Help and feedback

Check the in-app help text beside unfamiliar tools. For reproducible problems, open a [GitHub issue](https://github.com/Hexxis-cmd/Draft-A-Lore/issues) and include:

- the platform and device size;
- what you expected;
- what happened; and
- the steps that reproduce it.

GitHub issues are public. Do not attach a private manuscript or project unless you intentionally want to share it.
