Draft A Lore for Windows
========================

1. Keep every file in this folder together.
2. Open DraftALore.exe to launch the app in its own window.
3. If the launcher cannot run, open DraftALore.html in a modern browser instead.

Install-DraftALore.bat is optional. Run it only if you want desktop or Start Menu shortcuts.
It does not copy or uninstall the app; the shortcuts point to this folder.

Your projects are stored on this device. Export project backups regularly and keep a copy in
another folder or drive.
