# Draft A Lore 1.0.0

Draft A Lore is an offline writing, planning, and RPG-adventure studio. It keeps projects on your own device and requires no account.

## Downloads

- **DraftALore-Windows.zip** — recommended Windows package. Extract it, then open `DraftALore.exe`. Windows may identify this independent, unsigned launcher as an unknown publisher.
- **DraftALore.html** — the complete app in one browser-ready file.
- **DraftALore.apk** — Android package for direct installation.

## Included in this release

- A formatted manuscript editor with text highlighting, passage comments, find and replace, outline navigation, focus tools, sprints, and goals
- Characters, relationship editing, plot threads, timelines, lore, illustrations, and a fully editable mind map
- Cover art on the first book-preview page and illustrations assigned to specific pages
- A complete RPG builder with a visual Story Graph, stats, traits, items, inventory, equipment, conditions, effects, audio, and endings
- Playthrough testing with history, step back, inventory controls, change summaries, and explanations for locked choices
- Story Checkup for broken paths, impossible rules, and references to deleted content
- Project backups, recovery copies, snapshots, Save As branching, folder storage, and portable `.dalz` bundles
- Manuscript exports to text, Markdown, HTML, and Word, plus standalone playable-adventure and Twine exports
- Ten themes, responsive desktop and mobile layouts, reader settings, and read-aloud support

## Important data note

Projects are stored locally. Export backups regularly, especially before clearing browser data, uninstalling the Android app, or moving to another device.
