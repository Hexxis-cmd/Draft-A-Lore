Draft A Lore Privacy Policy

Effective and last updated August 30, 2026

Draft A Lore is an offline-first writing and RPG-building app by Hexxis-cmd (Daymien Vanhorn). It has no user accounts, advertising, analytics, tracking, or telemetry.

Information stored on your device

Projects, manuscripts, notes, character and RPG data, imported images, audio, fonts, preferences, recovery copies, and backups are processed and stored locally. The developer does not receive this content. Draft A Lore does not sell personal information.

Files, folders, imports, and exports

File and media pickers open only after you choose an import, export, image, audio, font, backup, or folder action. On Android, folder linking uses Android’s system folder picker. If you grant access, Android remembers permission for that selected folder so Draft A Lore can write the project manifest, chapter text, and project assets there. The app does not request broad access to all files. You can change the linked folder, revoke access in Android settings, clear app storage, or uninstall the app.

Exports and portable project bundles are created only when you request them. You control where exported files go and whether they are later shared.

Optional Google Fonts connection

Optional Online Fonts is off by default, and the app works without it. If you enable it while connected, Draft A Lore requests font stylesheets and font files from Google Fonts over HTTPS. Google may receive network information such as your IP address, which can reveal an approximate location, and browser or device request details. This connection is used only to load the fonts you enabled. Draft A Lore does not receive that network information. You can stop future font requests by turning Online Fonts off.

Google handles information it receives under the Google Privacy Policy.

Links to other sites

If you choose to open a web link from a manuscript or from Draft A Lore, the destination site may receive standard connection information and will apply its own privacy policy.

Retention and deletion

Local data remains until you delete it in Draft A Lore, use Settings → Clear All Data, clear the app or browser storage, uninstall the Android app, or replace it by restoring a backup. Files you exported or synchronized to a chosen folder remain there until you delete them yourself.

Security

Draft A Lore limits network use to user-enabled online fonts and uses HTTPS for those requests. Local projects rely on your device, browser profile, screen lock, and file protections; the app does not add separate encryption to project files. Keep private devices locked and maintain backups in a safe location.

Children

Draft A Lore is intended for a general audience age 13 and older and is not directed to children under 13. The developer does not knowingly collect personal information from children or other users.

Policy changes and contact

Material changes will be published on this page with a new effective date. Questions can be submitted through Draft A Lore’s GitHub Issues page. GitHub issues are public, so do not include a private manuscript, project, address, or other sensitive information.

This policy covers the official Draft A Lore Android, Windows, and browser releases.
